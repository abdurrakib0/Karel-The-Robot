# Karel the Robot

My exercises from Karel the Robot, the beginner world used in Stanford's **CS106A: Programming Methodology**. Karel moves around a grid, picks up and puts down beepers, and teaches decomposition and control flow before full Java.

Credit: Karel and `karel.jar` come from Stanford CS106A (Stanford Engineering Everywhere).

## How to run

1. Install a JDK and Eclipse (the repo includes Eclipse project files).
2. Import the folder as an existing project, with `karel.jar` on the build path.
3. Run any program class, for example `BlankKarel.java`. Worlds are in `worlds/`.
